## 🧭 What I do as a Forward Deployed Engineer

- **Own problems end to end with the customer.** Scope the requirement with the people who will use it, prototype fast, then harden it into a deployed pipeline or service — and support it after release.
- **AI task-data generation at scale.** Multi-step pipelines that produce training/evaluation tasks from persona files, task-architect prompts, mock data and generated configs, with structured QC scripts and review workflows so every task ships clean.
- **Code-migration benchmarks and agent evaluation.** Datasets and pipelines for JDK 8 → 17 migrations and framework-conversion tasks in TypeScript and Go: repo sourcing against licence/size/test criteria, golden diffs, an agent-driven patching loop with retries, Docker-based test execution and a hardness score that compares before/after code to grade task difficulty.
- **Prompt and eval engineering.** Iterating the prompt set behind a pipeline for clarity and QC compliance, and designing scoring that reflects how hard a task really is for an agent.
- **Pragmatic tooling.** Python and Bash automation, Docker harnesses, and lightweight tracking systems (Sheets / Apps Script) so client teams can see progress without another dashboard to maintain.
